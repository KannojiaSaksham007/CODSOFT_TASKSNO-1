# CODSOFT_TASKSNO 1
Task 1 – Rule-Based Chatbot 🤖

A simple rule-based chatbot built using Python that responds to user inputs using predefined rules and if-else statements.

📌 About the Project

This project was created as part of my CodSoft AI/ML Internship – Task 1.

The chatbot identifies common user queries and provides appropriate predefined responses. It demonstrates the basic concepts of Natural Language Processing (NLP) and conversational flow.

🛠️ Technologies Used
Python
Conditional Statements (if-else)
String Matching
Basic NLP Concepts
⚙️ How It Works
The user enters a message.
The chatbot checks the input against predefined keywords or patterns.
If a matching rule is found, the chatbot provides the corresponding response.
If no match is found, it gives a default response.
The conversation continues until the user chooses to exit.
